PUSTAKA LONTARA — VERSI MULTI-HALAMAN

File: index.html (Beranda), katalog.html (Katalog), buku-fisik.html (Buku Fisik),
koleksi.html (Favorit), tentang.html (Tentang), admin.html (Dashboard Admin),
style.css, script.js.

CARA MENJALANKAN: Ekstrak ZIP dan buka index.html melalui browser. Semua file
harus berada di folder yang sama.

PENTING: Data peminjaman pada versi ini tersimpan di localStorage browser.
Dashboard hanya melihat data pada browser/perangkat yang sama. Agar banyak
pengguna mengirim peminjaman dan admin melihat semuanya lintas perangkat,
diperlukan backend/database (misalnya Firebase atau Supabase) dan autentikasi admin.
Login pada versi ini masih simulasi lokal.

PENGATURAN WHATSAPP: Di script.js, ubah ADMIN_WA dari 628xxxxxxxxxx menjadi
nomor WhatsApp admin aktif, kode negara 62 tanpa tanda +.
