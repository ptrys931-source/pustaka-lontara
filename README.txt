PUSTAKA LONTARA — MOBILE RESPONSIVE FIX

Paket ini menggunakan file HTML, CSS, dan JavaScript terbaru yang Anda unggah.
Perbaikan hanya mengatur ulang tampilan pada layar handphone; warna sage/ivory,
logo, isi, fitur, dan tata letak desktop asli tetap dipertahankan.

Perubahan khusus handphone:
- Kartu buku tetap dua kolom, termasuk layar kecil.
- Sampul buku memakai rasio vertikal seperti referensi.
- Filter kategori/jenis dapat digeser ke samping.
- Navigasi bawah: Beranda, Katalog, Favorit, Admin.
- Header, pencarian, tombol, modal, dan dashboard admin lebih nyaman di HP.

CARA PAKAI:
1. Ekstrak ZIP.
2. Buka folder Pustaka-Lontara-Mobile-Fix di VS Code.
3. Pastikan file berada satu folder: HTML, style.css, script.js.
4. Jalankan index.html melalui browser.

PENTING:
- Jangan mengganti nama style.css atau script.js karena HTML memanggil nama tersebut.
- Untuk perubahan pada tampilan desktop, aturan CSS asli tetap digunakan.
- Data pinjaman tetap menggunakan localStorage sesuai kode asli, sehingga data
  tidak otomatis tersinkron antarperangkat.
